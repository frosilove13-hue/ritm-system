# Ритм — Система

Мобильный дневник питания и тренировок. Подсчитывает калории, составляет недельную программу и начисляет опыт за выполненные упражнения.

## GitHub Pages

В настройках репозитория откройте **Pages**. Укажите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Приложение собрано из статических файлов и запускается без установки зависимостей.

Чтобы добавить приложение на iPhone, откройте адрес GitHub Pages в Safari и выберите **Поделиться → На экран «Домой»**.

Записи остаются в хранилище браузера. Данные для разных адресов сайта хранятся отдельно. Напоминания можно добавить в «Календарь» Apple из настроек приложения.
